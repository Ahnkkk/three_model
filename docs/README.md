# 프로젝트 문서

기존 구현 기록과 후속 도면 변환 개발 계획을 모아 둔다.

| 문서 | 내용 | 상태 |
| --- | --- | --- |
| [실내 3D 시각화 개발 작업서](./DEVELOPMENT_PLAN.md) | 기존 거실 뷰어의 개발 범위·렌더링 구조 | 기존 계획 및 구현 기록 |
| [사무실 2안 재구성 개발 작업서](./OFFICE_RECONFIGURATION_PLAN.md) | 이미지 해석에 따른 사무실 2D·3D 구성 | 기존 계획 및 구현 기록 |
| [도면 → 3D 단기 계획](./FLOOR_PLAN_3D_SHORT_TERM_PLAN.md) | 입력 규격, 공용 변환, 이미지 보정, AI 추출 초안, 검증 | 후속 개발 제안·미구현 |
| [도면 → 3D 장기 계획](./FLOOR_PLAN_3D_LONG_TERM_PLAN.md) | 인식 고도화, CAD/PDF, 복잡한 공간, 저장·운영, 조건부 Agent | 후속 개발 제안·미구현 |

권장 읽기 순서: 단기 계획 → 장기 계획. 기존 구현의 배경은 앞의 두 작업서에서 확인한다.

기존 작업서의 완료 표시는 해당 작업서 범위에 대한 기록이다. 후속 계획의 업로드·자동 인식 기능이 구현되었다는 의미가 아니다.
